# 🌸 Perfumy – Perfume Shopping Website

A simple and elegant perfume shopping website developed using **HTML5 and CSS3**. This project focuses on creating an attractive, user-friendly interface for showcasing perfume products.

## 🚀 Features

- Clean and modern user interface
- Simple navigation bar
- Search bar design
- Perfume product showcase
- About Us and Contact Us sections
- Attractive CSS styling and layouts

## 🛠️ Technologies Used

- **HTML5** – Webpage structure
- **CSS3** – Website styling and design

## 🎯 Project Objective

The objective of this project is to strengthen frontend development skills by designing a visually appealing perfume shopping website using HTML and CSS.

## 💡 What I Learned

- Structuring webpages using HTML
- Applying CSS styling techniques
- Designing product cards and navigation bars
- Organizing webpage content
- Improving frontend development skills

## 🔮 Future Enhancements

- Add JavaScript functionality
- Implement a working product search
- Introduce shopping cart functionality
- Enhance mobile responsiveness

## 📌 Conclusion

Perfumy is a beginner-friendly frontend development project that demonstrates the practical application of HTML and CSS in creating an attractive perfume shopping website.
